# เกม "กระแสเงินสด" — กติกาและการ์ด (ฉบับแรก)

> ฉบับแรกทำแล้วที่ `/cashflow` (โค้ดกติกา: `src/lib/cashflow/`) ตัวเลขทุกตัวปรับได้
> กติกาเดินตามแนวเกมกระดานเรื่องการเงิน (สนามแข่งหนู → วงนอก) แต่ชื่อ ข้อความ และตัวเลขบนการ์ดเขียนใหม่ทั้งหมด

## ภาพรวม

- ผู้เล่น 2–6 คน URL: `/cashflow`
- **จอ host** (ทีวี/โน้ตบุ๊ก): สร้างห้อง แสดง QR ให้สแกน แสดงกระดาน ตำแหน่งผู้เล่น และการ์ดที่เปิด
- **มือถือผู้เล่น**: สแกน QR → พิมพ์ชื่อ เลือกสีหนู → ได้อาชีพแบบสุ่ม เล่นตาของตัวเองบนมือถือ (ทอยลูกเต๋า ซื้อ/ไม่ซื้อ กู้เงิน ขายทรัพย์สิน) และดูงบการเงินของตัวเอง
- ไม่ต้องมีบัญชี 3S1M ระบบคำนวณเงินให้ทั้งหมด ไม่ต้องจดเอง

## เป้าหมาย

ออกจาก **สนามแข่งหนู** ให้ได้ คือมี **รายได้จากทรัพย์สิน (passive income) มากกว่าค่าใช้จ่ายรวมต่อเดือน**
ออกได้แล้วขึ้น **ทางด่วน** (วงนอก) ชนะเกมบนทางด่วน (ดูหัวข้อทางด่วน)

## งบการเงินของผู้เล่น

| รายการ | ความหมาย |
|---|---|
| เงินเดือน | รายได้จากการทำงาน |
| รายได้จากทรัพย์สิน | ค่าเช่า เงินปันผล กำไรธุรกิจ (passive income) |
| ค่าใช้จ่ายรวม | ภาษี + ผ่อนบ้าน + ผ่อนรถ + บัตรเครดิต + ค่าใช้จ่ายอื่น + ค่าเลี้ยงลูก + ดอกเบี้ยเงินกู้ |
| **กระแสเงินสดต่อเดือน** | เงินเดือน + รายได้จากทรัพย์สิน − ค่าใช้จ่ายรวม |
| เงินสด | เงินที่มีอยู่ตอนนี้ |
| หนี้สิน | บ้าน รถ บัตรเครดิต เงินกู้ธนาคาร และจำนองของทรัพย์สินที่ซื้อ |

มือถือแต่ละคนแสดง "หลอดอิสรภาพ" = รายได้จากทรัพย์สิน ÷ ค่าใช้จ่ายรวม ถึง 100% = ออกจากสนามแข่งหนู

## กระดานสนามแข่งหนู (24 ช่อง วนรอบ)

โอกาสอยู่ทุกช่องเว้นช่อง ช่องระหว่างโอกาสเรียงเป็นชุดซ้ำ 3 รอบ: ตลาด → จ่ายซะ → ช่องพิเศษ (ทำบุญ / มีลูก / ตกงาน) → เงินเดือน · เงินเดือนและช่องพิเศษห่างกันทุก 8 ช่อง

| ช่อง | จำนวน | เกิดอะไร |
|---|---|---|
| โอกาส | 12 | เลือกได้ว่าจะเปิด **ดีลเล็ก** หรือ **ดีลใหญ่** แล้วตัดสินใจซื้อหรือไม่ |
| เงินเดือน | 3 | ได้รับ **กระแสเงินสดต่อเดือน** (ผ่านหรือตกช่องก็ได้ ขึ้นปุ่ม "รับเงินเดือน" ให้กดบนมือถือ ถ้าลืมกด ระบบให้ตอนจบตา) |
| ตลาด | 3 | เปิดการ์ดตลาด มีคนอยากซื้อทรัพย์สิน/ราคาหุ้นเปลี่ยน — **ทุกคน** ที่มีทรัพย์สินนั้นขายได้ |
| จ่ายซะ | 3 | เปิดการ์ดค่าใช้จ่ายฟุ่มเฟือย ต้องจ่ายทันที |
| ทำบุญ | 1 | บริจาค 10% ของรายได้รวม ได้สิทธิ์ทอย 2 ลูก 3 ตา (ไม่บริจาคก็ได้) |
| มีลูก | 1 | ค่าเลี้ยงลูกเพิ่ม 1 คน (สูงสุด 3 คน) |
| ตกงาน | 1 | จ่ายค่าใช้จ่ายรวม 1 เดือน และหยุดเดิน 2 ตา |

- ทอยลูกเต๋า 1 ลูก (ช่วงทำบุญได้ 2 ลูก)
- เงินไม่พอจ่าย → ต้องกู้ธนาคาร หรือขายทรัพย์สินก่อน

- กู้ได้ทีละ ฿10,000 ดอกเบี้ย/ค่าผ่อน ฿1,000 ต่อเดือนต่อ ฿10,000 (นับเป็นค่าใช้จ่าย)
- คืนได้ทีละ ฿10,000 ในตาของตัวเอง
- กู้ได้ไม่เกินจนกระแสเงินสดต่อเดือนติดลบ ถ้ายังไม่พอ ต้องขายทรัพย์สิน ถ้าขายหมดแล้วยังไม่พอ = ล้มละลาย (เริ่มอาชีพเดิมใหม่)
- เวลาต้องจ่ายแล้วเงินไม่พอ ระบบทำให้อัตโนมัติ: กู้ก่อน → ขายทรัพย์สินได้ครึ่งหนึ่งของเงินดาวน์ (เริ่มจากชิ้นที่กระแสเงินสดน้อยสุด) → ล้มละลาย

## การเล่นบนจอ host และมือถือ

**เข้าห้อง**
1. host เปิด `/cashflow` → สร้างห้อง → จอแสดง QR และรหัสห้อง
2. ผู้เล่นสแกน QR → พิมพ์ชื่อ → เลือกสี (สีที่มีคนเลือกแล้วกดไม่ได้)
3. ทุกคนเป็น **ไอคอนหนู** สีของตัวเอง พร้อมชื่อ ขึ้นบนจอ host ทันทีที่เข้าห้อง
4. host กด "เริ่มเกม" (ต้องมี 2–6 คน) → สุ่มอาชีพและลำดับการเล่น

**คำอธิบายก่อนเริ่มเกม** (host กดเปิดจากหน้ารอผู้เล่น เลื่อนทีละหน้า มือถือทุกเครื่องแสดงหน้าเดียวกัน)
1. เป้าหมายของเกม: ออกจากสนามแข่งหนู แล้วชนะบนทางด่วน
2. สนามแข่งหนูคืออะไร: ทำงาน → เงินเดือน → จ่าย → เงินหมด → วนซ้ำ
3. ESBI: ลูกจ้าง / ทำเอง (ฝั่งซ้าย ใช้เวลาแลกเงิน) และ เจ้าของระบบธุรกิจ / นักลงทุน (ฝั่งขวา ระบบและเงินทำงานแทน)
4. ในเกมนี้: เริ่มเป็น E แล้วซื้อทรัพย์สินเพื่อย้ายไปฝั่ง B และ I
5. ทรัพย์สิน (เอาเงินเข้า) vs หนี้สิน (เอาเงินออก)
6. วิธีเล่น — กดจบคำอธิบายแล้วกลับไปหน้า QR ให้คนที่มาทีหลังสแกนเข้า แล้ว host ค่อยกดเริ่มเกม

**ระหว่างเล่น**
- จอ host: กระดาน หนูทุกตัวบนช่องของตัวเอง ลูกเต๋าที่ทอย หนูเดินทีละช่อง การ์ดที่เปิดขึ้นกลางจอ และสรุปสั้น ๆ ของแต่ละคน (เงินสด หลอดอิสรภาพ)
- มือถือคนที่ถึงตา: ปุ่ม "ทอยลูกเต๋า" → หนูเดินบนจอ host → ตกช่องไหน มือถือขึ้นแอคชั่นของช่องนั้น (เช่น เลือกดีลเล็ก/ใหญ่ → เปิดการ์ด)
- เปิดการ์ดแล้ว ระบบส่ง **ตัวเลือกไปที่มือถือทุกคนที่เกี่ยวข้อง** พร้อมกัน เช่น
  - การ์ดหุ้นบริษัทยา ฿5: คนเปิดเห็น "ซื้อกี่หุ้น / ไม่ซื้อ" ส่วนคนที่ถือหุ้นบริษัทยาอยู่เห็น "ขายที่ ฿5 กี่หุ้น / ไม่ขาย"
  - การ์ดตลาด: ทุกคนที่มีทรัพย์สินตรงเงื่อนไขเห็น "ขาย / ไม่ขาย"
  - คนที่ไม่เกี่ยวข้องเห็นแค่การ์ดเดียวกับจอ host
- รอทุกคนที่เกี่ยวข้องตอบครบ (หรือหมดเวลา 30 วินาที = ไม่ทำอะไร) จอ host แสดงผลว่าใครซื้อ/ขายอะไร แล้วคนที่ถึงตากด "จบตา"

## ลำดับในหนึ่งตา (บนมือถือคนที่ถึงตา)

1. ทอยลูกเต๋า → ตัวหมากเดินบนจอ host
2. ผ่านหรือตกช่องเงินเดือน → กดปุ่ม "รับเงินเดือน" (ลืมกด ระบบให้ตอนจบตา)
3. ทำตามช่องที่หยุด (เลือกดีล/ซื้อ/จ่าย/ขาย)
4. ก่อนจบตา: กู้เงิน คืนเงินกู้ ปิดหนี้ ขายหุ้นได้
5. กด "จบตา" → ถึงตาคนถัดไป

- การ์ดตลาด และการ์ดหุ้น/กองทุน: ทุกคนที่เข้าเงื่อนไขกดขายบนมือถือตัวเองได้
- ดีลทรัพย์สิน/ธุรกิจที่คนเปิดไม่ซื้อ: กด **ไม่ซื้อ (จบ)** = ทิ้งไป หรือ **ขายสิทธิ์** (ถ้า host เปิดตัวเลือก 'ขายสิทธิ์ดีลได้') โดยประกาศค่านายหน้า 3%–15% ของเงินดาวน์ คนแรกที่กดรับจ่ายค่านายหน้าให้คนเปิด + เงินดาวน์ แล้วได้ทรัพย์สินไป · การ์ดหุ้น/กองทุน/เหรียญ/หุ้นกู้ ขายสิทธิ์ไม่ได้
